---
title: "Python SDK"
description: "Python client for the Membrane gRPC daemon."
---

The Python SDK communicates with `membraned` over gRPC using the typed `membrane.v1.MembraneService` protobuf contract. Arbitrary capture content uses `google.protobuf.Value`; memory records, graph nodes, graph edges, and response envelopes are typed protobuf messages converted into Python dataclasses.

## Installation

```bash
pip install -e clients/python
```

For development:

```bash
pip install -e clients/python[dev]
```

## Quick Start

```python
from membrane import MembraneClient, Sensitivity, SourceKind, TrustContext

client = MembraneClient("localhost:9090")

capture = client.capture_memory(
    {
        "ref": "src/auth.py",
        "text": "Refactored auth middleware and verified package tests",
        "file": "src/auth.py",
    },
    source_kind=SourceKind.EVENT,
    reason_to_remember="Keep the auth refactor available for future debugging",
    summary="Refactored auth middleware",
    sensitivity=Sensitivity.LOW,
    tags=["auth", "python"],
)
print(capture.primary_record.id)

trust = TrustContext(
    max_sensitivity=Sensitivity.MEDIUM,
    authenticated=True,
    actor_id="agent-1",
)

graph = client.retrieve_graph(
    "debug auth",
    trust=trust,
    memory_types=["entity", "semantic", "competence", "episodic"],
    root_limit=5,
    node_limit=20,
    max_hops=1,
)

for node in graph.nodes:
    print(f"[{node.record.type.value}] {node.record.id} root={node.root} hop={node.hop}")

client.close()
```

## Client Options

```python
client = MembraneClient(
    "membrane.example.com:443",
    tls=True,
    tls_ca_cert="/path/to/ca.pem",
    api_key="your-api-key",
    timeout=10.0,
)
```

<ParamField path="addr" type="str" default="localhost:9090">
  gRPC address of the Membrane daemon.
</ParamField>

<ParamField path="tls" type="bool">
  Use TLS transport.
</ParamField>

<ParamField path="tls_ca_cert" type="str">
  Optional CA certificate path. Supplying it implies TLS.
</ParamField>

<ParamField path="api_key" type="str">
  Bearer token sent in gRPC metadata. The SDK refuses to send it over
  plaintext gRPC to non-loopback addresses unless explicitly allowed.
</ParamField>

<ParamField path="allow_insecure_credentials" type="bool" default="false">
  Permit sending `api_key` over plaintext gRPC to a non-loopback address. Use
  only for trusted development networks, and enable the corresponding server
  setting as well. Production deployments should use TLS.
</ParamField>

<ParamField path="timeout" type="float">
  Default timeout in seconds for RPC calls.
</ParamField>

For a credential-bearing plaintext connection allowed only because its address
is loopback, the SDK disables gRPC HTTP proxying so proxy environment variables
cannot route the connection off-host. TLS and the explicit insecure development
override retain normal proxy behavior.

The client also supports the context-manager protocol:

```python
with MembraneClient("localhost:9090") as client:
    capture = client.capture_memory({"text": "Remember this"})
```

## Capture

```python
def capture_memory(
    content: Any,
    *,
    source_kind: SourceKind | str = SourceKind.EVENT,
    context: Any = None,
    reason_to_remember: str = "",
    proposed_type: MemoryType | str | None = None,
    summary: str = "",
    sensitivity: Sensitivity | str = Sensitivity.LOW,
    source: str = "python-client",
    tags: Sequence[str] | None = None,
    scope: str = "",
    timestamp: str | None = None,
) -> CaptureMemoryResult
```

Captures a rich memory candidate. `content` must be JSON-compatible. The SDK validates `source`, `source_kind`, `proposed_type`, `sensitivity`, `reason_to_remember`, `summary`, `timestamp`, `scope`, and `tags` before sending the RPC. A plain string is rejected for `tags` so `tags="auth"` cannot accidentally become `["a", "u", "t", "h"]`.

```python
capture = client.capture_memory(
    {
        "tool_name": "go test",
        "args": {"packages": ["./pkg/auth"]},
        "result": {"exit_code": 0},
    },
    source_kind=SourceKind.TOOL_OUTPUT,
    source="auth-agent",
    reason_to_remember="Successful auth package verification",
    summary="Auth package tests passed",
    tags=["auth", "tests"],
    scope="project-auth",
    sensitivity=Sensitivity.LOW,
)

print(capture.primary_record.id)
print(len(capture.created_records))
print(len(capture.edges))
```

`CaptureMemoryResult` contains:

| Field | Type |
|-------|------|
| `primary_record` | `MemoryRecord` |
| `created_records` | `list[MemoryRecord]` |
| `edges` | `list[GraphEdge]` |

Use `CaptureMemoryResult.from_dict(...)` when adapting JSON fixtures or non-gRPC envelopes. It accepts Python snake_case fields, Go struct field names such as `PrimaryRecord` and `CreatedRecords`, and protobuf JSON lower-camel fields such as `primaryRecord` and `createdRecords`.

## Retrieve Graph

```python
def retrieve_graph(
    task_descriptor: str,
    *,
    trust: TrustContext | None = None,
    memory_types: Sequence[MemoryType | str] | None = None,
    query_embedding: Sequence[float] | None = None,
    root_only: bool = False,
    min_salience: float = 0.0,
    root_limit: int = 10,
    node_limit: int = 25,
    edge_limit: int = 100,
    max_hops: int = 1,
) -> RetrieveGraphResult
```

Retrieves ranked root memories and a bounded graph neighborhood. The daemon can seed entity roots from both natural-language descriptors and explicit identifier tokens such as `github:BennettSchwartz/orchid` or `repo_path:pkg/auth`. When `trust.scopes` is empty, entity root seeding searches across all indexed scopes before trust filtering; when scopes are supplied, it searches those scopes plus unscoped global entities.

The SDK validates that `task_descriptor` is a string before sending the RPC. Pass an empty string only when you intentionally want salience-only root ranking.

```python
graph = client.retrieve_graph(
    "debug auth retry failures",
    trust=TrustContext(
        max_sensitivity=Sensitivity.MEDIUM,
        authenticated=True,
        actor_id="auth-agent",
        scopes=["project-auth"],
    ),
    query_embedding=[0.25, 0.5, 0.75],
    root_only=False,
    memory_types=["entity", "semantic", "competence", "episodic"],
    root_limit=8,
    node_limit=20,
    edge_limit=80,
    max_hops=1,
)

root_records = [node.record for node in graph.nodes if node.root]
```

Set `root_only=True` to skip neighbor expansion and return ranked roots only. This maps to the daemon's `max_hops=-1` sentinel and takes precedence over `max_hops`. The SDK rejects non-boolean `root_only`, non-integer `max_hops`, and `max_hops` values below `-1` before sending the RPC.

When `query_embedding` is supplied, the daemon uses it directly for graph root ranking. Non-empty vectors must be a sequence of numbers, contain only finite values, and include at least one non-zero value; the SDK validates this before sending the RPC. Strings, booleans, `NaN`, and infinities are rejected before protobuf conversion.

Graph budgets, metadata, and enum fields are validated client-side before protobuf conversion: `min_salience` must be finite and between `0` and `1`; `root_limit`, `node_limit`, and `edge_limit` must be integers from `0` to `10000`; `memory_types` must contain public API memory type values and is de-duplicated into canonical layer order; `trust.max_sensitivity` must be a public API sensitivity value; `trust.authenticated` must be boolean; `trust.actor_id` must be a string; and `trust.scopes` must be a sequence of non-empty strings. A plain string scope sequence is rejected so `scopes="prod"` cannot split into per-character scopes.

`RetrieveGraphResult` contains:

| Field | Type |
|-------|------|
| `nodes` | `list[GraphNode]` |
| `edges` | `list[GraphEdge]` |
| `root_ids` | `list[str]` |
| `selection` | `SelectionResult | None` |
| `diagnostics` | `list[RetrievalDiagnostic]` |

Use `RetrieveGraphResult.from_dict(...)` for JSON fixtures or non-gRPC envelopes. It accepts snake_case fields such as `root_ids` and `diagnostics`, Go-style fields such as `RootIDs`, `Selection`, `Scores`, `SourceID`, `TargetID`, and `Diagnostics`, and protobuf JSON lower-camel fields such as `rootIds`, `sourceId`, `targetId`, and `needsMore`. Nested memory records accept the same fixture casing, including Go-style fields such as `ID`, `CreatedAt`, `Relations`, and `AuditLog`, plus lower-camel fields such as `createdAt`, `updatedAt`, and `auditLog`. Nested interpretation metadata accepts fields such as `proposedType`, `canonicalEntityId`, `relationCandidates`, `referenceCandidates`, and `extractionConfidence`; payload oneofs such as `planGraph` are unwrapped for direct dataclass access. Semantic payloads normalize fields such as `revisionPolicy` and `supersededBy` while decoding `object` and validity condition `google.protobuf.Value` maps. Plan graph payloads normalize protobuf lower-camel fields such as `planId`, `inputsSchema`, `outputsSchema`, and `avgLatencyMs` into the SDK's snake_case keys while decoding nested `google.protobuf.Value` maps.

```python
def retrieve_by_id(
```

```python
record = client.retrieve_by_id(

```

`record_id` must be a non-empty string after trimming whitespace. The SDK rejects empty IDs before sending the RPC, matching daemon-side lookup validation.

## Revision

```python
client.supersede(old_id, new_record, "agent", "updated fact")
client.fork(source_id, forked_record, "agent", "different in staging")
client.retract(record_id, "agent", "no longer accurate")
client.merge([id1, id2], merged_record, "agent", "deduplicated")
client.contest(record_id, conflicting_ref, "agent", "conflicting evidence")
```

`new_record`, `forked_record`, and `merged_record` may be dictionaries matching the `MemoryRecord` wire shape or `MemoryRecord` dataclasses.

Revision methods reject empty required record IDs before transport. `merge` also requires at least one source ID, validates each source ID, and rejects duplicate source IDs; `contest` keeps `contesting_ref` optional so external evidence references can still be recorded without a graph relation. Replacement records are checked against the daemon's semantic, entity, and relation invariants before transport: semantic payloads need subject, predicate, object, and a `validity.mode`; entity payloads need `canonical_name`, and any entity identifiers need non-empty `namespace` and `value` fields; relations need a non-empty normalized predicate, non-empty `target_id`, and a finite weight in `[0, 1]` when supplied. Outbound semantic and entity payloads accept both SDK snake_case fields and Go-style JSON fields such as `Kind`, `Subject`, `Predicate`, `Object`, `Validity`, `CanonicalName`, `PrimaryType`, and `Identifiers`; the SDK normalizes them into the protobuf oneof before sending the RPC.

## Reinforcement

```python
client.reinforce(record_id, "agent", "used successfully")
client.penalize(record_id, 0.2, "agent", "not useful for this task")
```

`reinforce` and `penalize` reject empty record IDs before transport. `penalize` also rejects negative, `NaN`, infinite, boolean, and non-numeric amounts before sending the RPC, matching daemon-side validation.

```python
metrics = client.get_metrics()

```

`get_metrics()` is typed as `MetricsSnapshot`, including pgvector coverage fields such as `embedded_records`, `missing_embeddings`, and `embedding_coverage`.

## Types And Enums

```python
from membrane import (
    BUILTIN_ENTITY_TYPES,
    EntityPayload,
    EntityType,
    GraphPredicate,
    MemoryRecord,
    MemoryType,
    Sensitivity,
    SourceKind,
    TrustContext,
)
```

Memory types:

```python
MemoryType.EPISODIC
MemoryType.WORKING
MemoryType.SEMANTIC
MemoryType.COMPETENCE
MemoryType.PLAN_GRAPH
MemoryType.ENTITY
```

Entity payload helpers accept the documented snake_case shape plus protobuf lower-camel and Go-style field names. Returned record payload dictionaries are normalized to snake_case for `canonical_name`, `primary_type`, `aliases`, and `identifiers`.

Built-in entity ontology values are open-ended. Use `EntityType.OTHER` or any project-specific string when none of the built-ins fit.

Graph predicate constants cover Membrane-generated structural edges and common relation candidates:

```python
GraphPredicate.MENTIONS_ENTITY
GraphPredicate.DERIVED_SEMANTIC
GraphPredicate.DEPENDS_ON
GraphPredicate.DEPENDENCY_OF
GraphPredicate.SUPPORTS
GraphPredicate.SUPPORTED_BY
GraphPredicate.SUPERSEDES
GraphPredicate.SUPERSEDED_BY
GraphPredicate.CONTESTED_BY
GraphPredicate.CONTESTS
```

`normalize_graph_predicate(value)` lowercases model- or user-provided predicate
names, splits camelCase/acronym boundaries, and treats punctuation as separators.
`normalize_semantic_predicate(value)` applies the same canonical spelling for
semantic subject-predicate-object facts before capture or direct record writes.
`inverse_graph_predicate(value)` returns the reverse-edge predicate for Membrane's built-ins and
`inverse_of_<normalized_predicate>` for custom predicates.
