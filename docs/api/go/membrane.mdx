Import path: `github.com/BennettSchwartz/membrane/pkg/membrane`

The `membrane` package is the embedded Go entry point. It initializes storage, ingestion, retrieval, decay, revision, consolidation, embeddings, and metrics from a single `Config`.

## Constructors

### New

```go
func New(cfg *Config) (*Membrane, error)
```

Initializes all subsystems from `Config` and returns a ready-to-start `Membrane`.

```go
cfg := membrane.DefaultConfig()
cfg.PostgresDSN = os.Getenv("MEMBRANE_POSTGRES_DSN")

m, err := membrane.New(cfg)
if err != nil {
    log.Fatal(err)
}
defer m.Stop()

if err := m.Start(context.Background()); err != nil {
    log.Fatal(err)
}
```

### DefaultConfig

```go
func DefaultConfig() *Config
```

Returns defaults for Postgres-backed storage, daemon listen address, schedulers, retrieval limits, and policy settings. `PostgresDSN` must be set directly or through `MEMBRANE_POSTGRES_DSN` before constructing a `Membrane`.

### LoadConfig

```go
func LoadConfig(path string) (*Config, error)
```

Reads a YAML config file and overlays it onto `DefaultConfig`. Unknown YAML fields are rejected so removed keys and typos fail during startup.

## Lifecycle

```go
func (m *Membrane) Start(ctx context.Context) error
func (m *Membrane) Stop() error
```

`Start` begins background decay and consolidation schedulers. If embeddings are configured, it also launches one missing-embedding backfill for embeddable records, including first-class entities. Backfill continues past individual record failures but reports an aggregate error in the startup log so incomplete vector coverage is visible. Repeated `Start` calls do not launch duplicate background work. `Stop` cancels the Membrane-owned background context, waits for schedulers and backfill to finish, and then closes the store; starting again after `Stop` returns an error.

## Capture

```go
func (m *Membrane) CaptureMemory(ctx context.Context, req ingestion.CaptureMemoryRequest) (*ingestion.CaptureMemoryResponse, error)
```

Captures a graph-aware memory candidate and returns the primary record plus any linked records or edges.

```go
capture, err := m.CaptureMemory(ctx, ingestion.CaptureMemoryRequest{
    Source:           "auth-agent",
    SourceKind:       "tool_output",
    Content:          map[string]any{
        "tool_name": "go test",
        "args":      map[string]any{"packages": []string{"./pkg/auth"}},
        "result":    map[string]any{"exit_code": 0},
    },
    ReasonToRemember: "Successful auth package verification",
    Summary:          "Auth package tests passed",
    Tags:             []string{"auth", "tests"},
    Scope:            "project-auth",
    Sensitivity:      schema.SensitivityLow,
})
```

```go
func (m *Membrane) RecordOutcome(ctx context.Context, req ingestion.IngestOutcomeRequest) (*schema.MemoryRecord, error)
```

Attaches an outcome to an existing episodic record. This delegates to the lower-level ingestion service outcome path.

## Retrieval

```go
func (m *Membrane) RetrieveGraph(ctx context.Context, req *retrieval.RetrieveGraphRequest) (*retrieval.RetrieveGraphResponse, error)
func (m *Membrane) RetrieveByID(ctx context.Context, id string, trust *retrieval.TrustContext) (*schema.MemoryRecord, error)
```

`RetrieveGraph` returns ranked roots and a bounded graph neighborhood. When request limits are zero, the facade applies the graph defaults from `Config` on an internal copy of the request, so the caller's struct is not mutated. Negative root, node, and edge limits are rejected; use `MaxHops: -1` for roots-only retrieval.

```go
graph, err := m.RetrieveGraph(ctx, &retrieval.RetrieveGraphRequest{
    TaskDescriptor: "debug auth retries",
    Trust: retrieval.NewTrustContext(
        schema.SensitivityMedium,
        true,
        "auth-agent",
        []string{"project-auth"},
    ),
    MemoryTypes: []schema.MemoryType{
        schema.MemoryTypeEntity,
        schema.MemoryTypeSemantic,
        schema.MemoryTypeCompetence,
        schema.MemoryTypeEpisodic,
    },
    RootLimit: 8,
    NodeLimit: 20,
    EdgeLimit: 80,
    MaxHops:   1,
})
if err != nil {
    log.Fatal(err)
}

for _, node := range graph.Nodes {
    fmt.Println(node.Record.ID, node.Record.Type, node.Root, node.Hop)
}
```

## Config

```go
type Config struct { ... }
```

Important fields:

<ParamField path="PostgresDSN" type="string">
  PostgreSQL connection string. Falls back to `MEMBRANE_POSTGRES_DSN`.
</ParamField>

<ParamField path="ListenAddr" type="string" default="127.0.0.1:9090">
  Daemon gRPC listen address.
</ParamField>

<ParamField path="DefaultSensitivity" type="string" default="low">
  Default sensitivity assigned during capture.
</ParamField>

<ParamField path="ReadMaxSensitivity" type="string" default="low">
  Highest record sensitivity visible through gRPC read operations. Falls back
  to `MEMBRANE_READ_MAX_SENSITIVITY` when the config field is empty.
</ParamField>

<ParamField path="ReadScopes" type="[]string" default='["default"]'>
  Scopes visible through gRPC read operations. `MEMBRANE_READ_SCOPES` accepts
  a comma-separated replacement list.
</ParamField>

<ParamField path="WriteMaxSensitivity" type="string" default="low">
  Highest record sensitivity mutable through gRPC. Falls back to
  `MEMBRANE_WRITE_MAX_SENSITIVITY` when the config field is empty.
</ParamField>

<ParamField path="WriteScopes" type="[]string" default='["default"]'>
  Scopes mutable through gRPC. `MEMBRANE_WRITE_SCOPES` accepts a
  comma-separated replacement list.
</ParamField>

<ParamField path="DecayInterval" type="time.Duration" default="1h">
  How often the background decay scheduler runs.
</ParamField>

<ParamField path="ConsolidationInterval" type="time.Duration" default="6h">
  How often the background consolidation scheduler runs.
</ParamField>

<ParamField path="GraphDefaultRootLimit" type="int" default="10">
  Default graph root limit for `RetrieveGraph`.
</ParamField>

<ParamField path="GraphDefaultNodeLimit" type="int" default="25">
  Default graph node limit for `RetrieveGraph`.
</ParamField>

<ParamField path="GraphDefaultEdgeLimit" type="int" default="100">
  Default graph edge limit for `RetrieveGraph`.
</ParamField>

<ParamField path="GraphDefaultMaxHops" type="int" default="1">
  Default graph expansion depth.
</ParamField>

<ParamField path="SelectionConfidenceThreshold" type="float64" default="0.7">
  Minimum finite selector confidence for competence and plan graph candidates. Range: `0` to `1`.
</ParamField>

<ParamField path="EmbeddingEndpoint" type="string">
  HTTP endpoint used to generate embeddings. `EmbeddingModel` is required when this is set. Falls back to `MEMBRANE_EMBEDDING_ENDPOINT`. Semantic search is disabled when empty.
</ParamField>

<ParamField path="EmbeddingModel" type="string">
  Embedding model name sent to the embedding endpoint. Falls back to `MEMBRANE_EMBEDDING_MODEL`.
</ParamField>

<ParamField path="EmbeddingDimensions" type="int" default="1536">
  Expected embedding vector length. Falls back to `MEMBRANE_EMBEDDING_DIMENSIONS` when the value is still the default. Must match the configured model and the fixed pgvector column shape.
</ParamField>

<ParamField path="EmbeddingAPIKey" type="string">
  Authentication key for the embedding endpoint. Falls back to `MEMBRANE_EMBEDDING_API_KEY`.
</ParamField>

<ParamField path="LLMEndpoint" type="string">
  HTTP endpoint used for LLM-backed semantic extraction during consolidation. `LLMModel` is required when this is set. Falls back to `MEMBRANE_LLM_ENDPOINT`.
</ParamField>

<ParamField path="LLMModel" type="string">
  Chat model name sent to the consolidation LLM endpoint. Falls back to `MEMBRANE_LLM_MODEL`.
</ParamField>

<ParamField path="LLMAPIKey" type="string">
  Authentication key for the consolidation LLM endpoint. Falls back to `MEMBRANE_LLM_API_KEY`.
</ParamField>

<ParamField path="IngestLLMEnabled" type="bool" default="false">
  Enables ingest-side interpretation during `CaptureMemory`. `IngestLLMEndpoint` and `IngestLLMModel` are required when enabled.
</ParamField>

<ParamField path="IngestLLMEndpoint" type="string">
  HTTP endpoint used for ingest-side interpretation. Falls back to `MEMBRANE_INGEST_LLM_ENDPOINT`.
</ParamField>

<ParamField path="IngestLLMModel" type="string">
  Chat model name sent to the ingest-side interpretation endpoint. Falls back to `MEMBRANE_INGEST_LLM_MODEL`.
</ParamField>

<ParamField path="IngestLLMAPIKey" type="string">
  Authentication key for the ingest-side interpretation endpoint. Falls back to `MEMBRANE_INGEST_LLM_API_KEY`.
</ParamField>

<ParamField path="APIKey" type="string">
  Bearer token for gRPC clients. Falls back to `MEMBRANE_API_KEY`. A
  non-loopback listener requires TLS when this is set unless
  `AllowInsecureCredentials` is explicitly enabled.
</ParamField>

<ParamField path="AllowInsecureCredentials" type="bool" default="false">
  Permits API-key authentication over plaintext gRPC on non-loopback listeners.
  Use only for trusted development networks; production deployments should use TLS.
</ParamField>

<ParamField path="RateLimitPerSecond" type="int" default="100">
  Per-principal gRPC request rate limit. API-key-authenticated requests share a
  stable, non-secret key fingerprint bucket across peer addresses; when API-key
  authentication is disabled, the bucket uses normalized source IP. Changing a
  source port does not reset either quota. `0` disables rate limiting.
</ParamField>
