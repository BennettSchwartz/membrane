Import path: `github.com/BennettSchwartz/membrane/pkg/ingestion`

The `ingestion` package classifies, validates, interprets, and persists data as `MemoryRecord` values. Most applications should call `m.CaptureMemory` through the top-level `membrane.Membrane` facade. Import this package for request types or when constructing `Service` directly.

## Service

```go
type Service struct { ... }

func NewService(store storage.Store, classifier *Classifier, policy *PolicyEngine) *Service
func NewServiceWithInterpreter(store storage.Store, classifier *Classifier, policy *PolicyEngine, interpreter Interpreter) *Service
```

`membrane.New` wires these dependencies automatically. `NewServiceWithInterpreter` enables LLM-backed capture interpretation and candidate resolution.

## CaptureMemory

```go
func (s *Service) CaptureMemory(ctx context.Context, req CaptureMemoryRequest) (*CaptureMemoryResponse, error)
```

Captures a graph-aware memory candidate. It creates a primary record, attaches interpretation metadata, resolves mentions and references, and can create linked entity records.

Capture enforces exported work ceilings before lookup and again immediately before its transaction: `MaxCaptureMentions`, `MaxCaptureReferenceCandidates`, and `MaxCaptureRelationCandidates` are 64 each; `MaxCaptureInterpretationWorkItems` is a shared 128-item ceiling; and entity lookups, aliases, topical labels, and candidate terms have their own finite caps. Interpreter and resolver output is deterministically truncated to those limits, so custom model output cannot turn one call into proportional record and edge creation.

### CaptureMemoryRequest

<ParamField path="Source" type="string">
  Actor or system that produced the content.
</ParamField>

<ParamField path="SourceKind" type="string">
  Capture shape: `event`, `tool_output`, `observation`, `working_state`, or `agent_turn`. Leave empty to use the default `event` shape.
</ParamField>

<ParamField path="Content" type="any" required>
  JSON-compatible raw content.
</ParamField>

<ParamField path="Context" type="any">
  Optional JSON-compatible context.
</ParamField>

<ParamField path="ReasonToRemember" type="string">
  Reason the content should be retained.
</ParamField>

<ParamField path="ProposedType" type="schema.MemoryType">
  Optional requested memory type: `episodic`, `working`, `semantic`, `competence`, `plan_graph`, or `entity`. Invalid non-empty values are rejected before interpretation.
</ParamField>

<ParamField path="Summary" type="string">
  Human-readable summary.
</ParamField>

<ParamField path="Tags" type="[]string">
  Labels for categorization and filtering.
</ParamField>

<ParamField path="Scope" type="string">
  Visibility scope.
</ParamField>

<ParamField path="Sensitivity" type="schema.Sensitivity">
  Sensitivity classification. Defaults to `low` when empty.
</ParamField>

<ParamField path="Timestamp" type="time.Time">
  Capture timestamp. Defaults to `time.Now().UTC()` when zero.
</ParamField>

### CaptureMemoryResponse

<ResponseField name="PrimaryRecord" type="*schema.MemoryRecord">
  The primary record stored for the capture.
</ResponseField>

<ResponseField name="CreatedRecords" type="[]*schema.MemoryRecord">
  Additional records created during capture, commonly entity records.
</ResponseField>

<ResponseField name="Edges" type="[]schema.GraphEdge">
  Graph edges materialized during capture.
</ResponseField>

```go
capture, err := m.CaptureMemory(ctx, ingestion.CaptureMemoryRequest{
    Source:           "auth-agent",
    SourceKind:       "tool_output",
    Content:          map[string]any{
        "tool_name": "go test",
        "args":      map[string]any{"packages": []string{"./pkg/auth"}},
        "result":    map[string]any{"exit_code": 0},
    },
    ReasonToRemember: "Successful auth package verification",
    Summary:          "Auth package tests passed",
    Tags:             []string{"auth", "tests"},
    Scope:            "project-auth",
    Sensitivity:      schema.SensitivityLow,
})
```

## Interpretation

```go
type Interpreter interface {
    Interpret(ctx context.Context, req InterpretRequest) (*schema.Interpretation, error)
}

type CandidateResolver interface {
    Resolve(ctx context.Context, req ResolveRequest) (*schema.Interpretation, error)
}
```

When configured, the interpreter proposes summaries, memory types, mentions, relation candidates, and reference candidates. If it also implements `CandidateResolver`, capture performs a second pass with bounded existing-record candidates before writing graph edges. The candidate set is ranked by match score, recency, and ID so repeated captures give the resolver stable context even when scores tie. With `CaptureMemoryWithAccess`, direct resolver IDs and entity matches must come from that bounded set, and a field-only authorization lookup inside the transaction rechecks current scope and sensitivity before both access callbacks run. A missing, changed, unsupported, or out-of-policy target remains unresolved without a full-record lookup. Trusted `CaptureMemory` retains legacy entity lookup and exact semantic reuse: explicit observations can reinforce an existing exact fact after entity canonicalization, append evidence and provenance, and return provenance edges. Policy-restricted capture instead creates a fresh semantic fact so it never hydrates unbounded append-only history or overwrites a projection with omitted history. Scoped observations canonicalize subjects and string objects through same-scope entities first, then unscoped global entities. Exact semantic reuse in the trusted path compares string objects by trimmed text and structured objects by stable JSON. Capture finalization deduplicates repeated `(source, predicate, target)` edges before returning the response and updating the primary record.

## Compatibility Helpers

The package still exposes the older one-method-per-shape helpers for embedded
callers and for `CaptureMemory` internals. Treat them as compatibility APIs:
new capture code should prefer `Service.CaptureMemory` or
`membrane.Membrane.CaptureMemory` so interpretation, entity resolution,
semantic fact reuse, and graph edges all stay on the same path. `IngestOutcome`
is the exception here; it updates an existing episodic record and remains the
lower-level implementation behind `membrane.Membrane.RecordOutcome`.

### IngestEvent

```go
func (s *Service) IngestEvent(ctx context.Context, req IngestEventRequest) (*schema.MemoryRecord, error)
```

Creates an episodic record from a discrete event. Prefer `CaptureMemory` with
`SourceKind: "event"` for new capture code.

```go
rec, err := svc.IngestEvent(ctx, ingestion.IngestEventRequest{
    Source:    "agent-core",
    EventKind: "user_input",
    Ref:       "msg-abc123",
    Summary:   "User asked about deployment strategy",
    Tags:      []string{"deployment", "strategy"},
})
```

### IngestToolOutput

```go
func (s *Service) IngestToolOutput(ctx context.Context, req IngestToolOutputRequest) (*schema.MemoryRecord, error)
```

Creates an episodic record with a populated tool graph node. Prefer
`CaptureMemory` with `SourceKind: "tool_output"` for new capture code.

```go
rec, err := svc.IngestToolOutput(ctx, ingestion.IngestToolOutputRequest{
    Source:   "agent-core",
    ToolName: "run_bash",
    Args:     map[string]any{"command": "ls -la"},
    Result:   "total 8",
})
```

### IngestObservation

```go
func (s *Service) IngestObservation(ctx context.Context, req IngestObservationRequest) (*schema.MemoryRecord, error)
```

Creates a semantic record from a subject-predicate-object observation. Subject
terms and string object terms are linked to a same-scope entity when one exists,
otherwise to a matching global entity. Prefer `CaptureMemory` with
`SourceKind: "observation"` for new capture code because it can also reuse
exact semantic facts and return provenance edges.

```go
rec, err := svc.IngestObservation(ctx, ingestion.IngestObservationRequest{
    Source:    "agent-core",
    Subject:   "user:alice",
    Predicate: "prefers_language",
    Object:    "Go",
    Tags:      []string{"preference"},
})
```

### IngestOutcome

```go
func (s *Service) IngestOutcome(ctx context.Context, req IngestOutcomeRequest) (*schema.MemoryRecord, error)
```

Updates an existing episodic record with outcome data.

```go
updated, err := svc.IngestOutcome(ctx, ingestion.IngestOutcomeRequest{
    Source:         "agent-core",
    TargetRecordID: rec.ID,
    OutcomeStatus:  schema.OutcomeStatusSuccess,
})
```

### IngestWorkingState

```go
func (s *Service) IngestWorkingState(ctx context.Context, req IngestWorkingStateRequest) (*schema.MemoryRecord, error)
```

Creates a working record from a snapshot of current task state. Prefer
`CaptureMemory` with `SourceKind: "working_state"` for new capture code.

```go
rec, err := svc.IngestWorkingState(ctx, ingestion.IngestWorkingStateRequest{
    Source:         "agent-core",
    ThreadID:       "session-xyz",
    State:          schema.TaskStateExecuting,
    NextActions:    []string{"run tests", "review output"},
    ContextSummary: "Refactoring the auth module",
})
```

## Policy Defaults

The `PolicyEngine` assigns default confidence and decay profile values by source shape and memory type.

| Source kind | Default confidence |
|-------------|--------------------|
| Event | 0.8 |
| Tool output | 0.9 |
| Observation | 0.7 |
| Outcome | 0.85 |
| Working state | 1.0 |

| Memory type | Default half-life |
|-------------|-------------------|
| `episodic` | 1 hour |
| `working` | 1 day |
| `semantic` | 30 days |
| `competence` | 30 days |
| `plan_graph` | 30 days |
| `entity` | 30 days |
